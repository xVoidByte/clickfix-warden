ClickFix Warden 隱私權政策

最後更新日期 2026年10月31日

簡要說明

ClickFix Warden 不會收集、在任何伺服器上儲存、出售或分享任何關於你的資料。它沒有帳戶、沒有分析、沒有遙測，也沒有自己的伺服器。所有檢查都在你的瀏覽器內進行。

擴充功能會查看什麼，在哪裡查看

  • 你開啟的頁面網址會與儲存在你瀏覽器內的公開威脅資料庫副本比對。網址絕不會傳送到任何地方。
  • 頁面試圖放入你剪貼簿的文字以及你複製的文字，會在頁面內檢查是否含有隱藏指令。這些文字絕不會傳送到任何地方。
  • 頁面上的文字會在頁面內讀取，以找出「按 Win 和 R，然後按 Ctrl 和 V」之類的指示。這些文字絕不會傳送到任何地方。
  • 你貼到網站中的文字會被檢查是否為帶有授權碼的登入連結。這些文字絕不會傳送到任何地方。
  • 頁面來源伺服器的 IP 位址（由瀏覽器提供）會與本機的資料庫副本比對。

保留在你電腦上的內容

  • 你的設定和信任的網站清單。
  • 封鎖或警告內容的記錄，最多 500 筆，你可以隨時匯出或清除。登入代碼會從記錄中移除。
  • 下載的威脅資料庫和偵測規則副本。

設定儲存在瀏覽器的本機儲存空間中，而不是瀏覽器同步中，因此也不會傳到你的瀏覽器帳戶。

選用檢查

  • 瀏覽記錄檢查。只有在你按下按鈕時，擴充功能才會要求讀取你瀏覽記錄的權限，在你的瀏覽器內將其與本機資料庫比對，並向你顯示結果。不會傳送任何內容，你只要按一下就能交還該權限。
  • 擴充功能檢查。只有在你按下按鈕時，擴充功能才會要求列出你已安裝擴充功能的權限，並在你的瀏覽器內將它們的 ID 與已知的惡意擴充功能清單比對。你只要按一下就能交還該權限。

唯一的網路請求

擴充功能大約每小時從由 GitHub Pages 代管的 xvoidbyte.github.io 下載一次威脅資料庫和偵測規則的最新變更，並每天下載一次遭回報下載連結的完整清單，每個檔案都附有數位簽章。這些請求不帶任何識別碼，也不含任何關於你瀏覽活動的資訊。與造訪任何網頁時一樣，GitHub 會依據 GitHub 一般隱私權聲明接收你的 IP 位址和瀏覽器版本。你可以在設定中關閉這些更新，之後擴充功能會繼續使用內建規則運作。

如果你點選警告中的「詳細資料」連結，瀏覽器會像開啟你點選的任何連結一樣，在新分頁中開啟 abuse.ch 上的公開報告。

回報的來源

資料庫是根據 abuse.ch 營運的公開專案 URLhaus、ThreatFox 和 Feodo Tracker 建立的。擴充功能從不向它們回報任何內容。

組織

管理員可以透過瀏覽器原則設定擴充功能的選項。這些設定是從瀏覽器讀取的，同樣不會傳送到任何地方。

變更與聯絡

本政策的任何變更都會發布在此頁面和專案存放庫中。如有疑問，可以透過 GitHub Issues 提出。
