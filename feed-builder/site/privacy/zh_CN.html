ClickFix Warden 隐私政策

最后更新于 2026年10月31日

简要说明

ClickFix Warden 不会收集、在任何服务器上存储、出售或分享任何关于你的数据。它没有账户、没有分析、没有遥测，也没有自己的服务器。所有检查都在你的浏览器内进行。

扩展程序会查看什么，在哪里查看

  • 你打开的页面的地址会与存储在你浏览器内的公开威胁数据库副本进行比对。地址绝不会被发送到任何地方。
  • 页面试图放入你剪贴板的文本以及你复制的文本，会在页面内被检查是否含有隐藏命令。这些文本绝不会被发送到任何地方。
  • 页面上的文本会在页面内被读取，以发现诸如“按 Win 和 R，然后按 Ctrl 和 V”之类的指示。这些文本绝不会被发送到任何地方。
  • 你粘贴到网站中的文本会被检查是否为带有授权码的登录链接。这些文本绝不会被发送到任何地方。
  • 页面所在服务器的 IP 地址（由浏览器提供）会与本地的数据库副本进行比对。

保留在你电脑上的内容

  • 你的设置和受信任网站列表。
  • 拦截或警告记录的日志，最多 500 条，你可以随时导出或清除。登录代码会从日志中移除。
  • 下载的威胁数据库和检测规则副本。

设置保存在浏览器的本地存储中，而不是浏览器同步中，因此也不会传到你的浏览器账户。

可选检查

  • 历史记录检查。只有在你按下按钮时，扩展程序才会请求读取你浏览历史记录的权限，在你的浏览器内将其与本地数据库进行比对，并向你显示结果。不会发送任何内容，你只需点击一下即可交还该权限。
  • 扩展程序检查。只有在你按下按钮时，扩展程序才会请求列出你已安装扩展程序的权限，并在你的浏览器内将它们的 ID 与已知恶意扩展程序列表进行比对。你只需点击一下即可交还该权限。

仅有的网络请求

扩展程序大约每小时从由 GitHub Pages 托管的 xvoidbyte.github.io 下载一次威胁数据库和检测规则的最新变更，并每天下载一次被举报下载链接的完整列表，每个文件都附有数字签名。这些请求不带任何标识符，也不含任何关于你浏览活动的信息。与访问任何网页时一样，GitHub 会依据 GitHub 一般隐私声明接收你的 IP 地址和浏览器版本。你可以在设置中关闭这些更新，之后扩展程序会继续使用内置规则工作。

如果你点击警告中的“详情”链接，浏览器会像打开你点击的任何链接一样，在新标签页中打开 abuse.ch 上的公开报告。

举报的来源

数据库根据 abuse.ch 运营的公开项目 URLhaus、ThreatFox 和 Feodo Tracker 构建。扩展程序从不向它们回报任何内容。

组织

管理员可以通过浏览器策略设置扩展程序的选项。这些设置从浏览器中读取，同样不会被发送到任何地方。

变更与联系

本政策的任何变更都会发布在此页面和项目仓库中。如有疑问，可以通过 GitHub Issues 提出。
