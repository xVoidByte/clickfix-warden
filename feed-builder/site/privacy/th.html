นโยบายความเป็นส่วนตัวของ ClickFix Warden

อัปเดตล่าสุด 31 ตุลาคม 2569

สรุปสั้นๆ

ClickFix Warden ไม่เก็บรวบรวม ไม่จัดเก็บไว้บนเซิร์ฟเวอร์ใด ไม่ขาย และไม่แบ่งปันข้อมูลใดๆ เกี่ยวกับคุณ ไม่มีบัญชี ไม่มีการวิเคราะห์ ไม่มีการส่งข้อมูลการใช้งาน และไม่มีเซิร์ฟเวอร์ของตัวเอง การตรวจสอบทุกอย่างเกิดขึ้นภายในเบราว์เซอร์ของคุณ

สิ่งที่ส่วนขยายตรวจดู และตรวจดูที่ใด

  • ที่อยู่ของหน้าที่คุณเปิด จะถูกเปรียบเทียบกับสำเนาฐานข้อมูลภัยคุกคามสาธารณะที่เก็บไว้ในเบราว์เซอร์ของคุณ ที่อยู่จะไม่ถูกส่งไปที่ใดเลย
  • ข้อความที่หน้าเว็บพยายามใส่ลงในคลิปบอร์ดของคุณ และข้อความที่คุณคัดลอก จะถูกตรวจหาคำสั่งที่ซ่อนอยู่ภายในหน้านั้น ข้อความจะไม่ถูกส่งไปที่ใดเลย
  • ข้อความบนหน้าเว็บ จะถูกอ่านภายในหน้านั้นเพื่อหาคำแนะนำ เช่น "กด Win กับ R แล้วกด Ctrl กับ V" ข้อความจะไม่ถูกส่งไปที่ใดเลย
  • ข้อความที่คุณวางลงในเว็บไซต์ จะถูกตรวจหาลิงก์ลงชื่อเข้าใช้ที่มีรหัสการให้สิทธิ์ ข้อความจะไม่ถูกส่งไปที่ใดเลย
  • ที่อยู่ IP ของเซิร์ฟเวอร์ที่ส่งหน้าเว็บมา ตามที่เบราว์เซอร์รายงาน จะถูกเปรียบเทียบกับสำเนาฐานข้อมูลในเครื่อง

สิ่งที่เก็บไว้ในคอมพิวเตอร์ของคุณ

  • การตั้งค่าและรายการเว็บไซต์ที่คุณเชื่อถือ
  • บันทึกสิ่งที่ถูกบล็อกหรือได้รับคำเตือน สูงสุด 500 รายการ ซึ่งคุณส่งออกหรือล้างได้ทุกเมื่อ รหัสลงชื่อเข้าใช้จะถูกลบออกจากบันทึก
  • สำเนาฐานข้อมูลภัยคุกคามและกฎการตรวจจับที่ดาวน์โหลดมา

การตั้งค่าจะเก็บไว้ในพื้นที่จัดเก็บภายในของเบราว์เซอร์ ไม่ใช่ในการซิงค์ของเบราว์เซอร์ จึงไม่ไปถึงบัญชีเบราว์เซอร์ของคุณด้วย

การตรวจสอบที่เลือกใช้ได้

  • ตรวจสอบประวัติ ส่วนขยายจะขอสิทธิ์อ่านประวัติการท่องเว็บของคุณเฉพาะเมื่อคุณกดปุ่มเท่านั้น จากนั้นจะเปรียบเทียบกับฐานข้อมูลในเครื่องภายในเบราว์เซอร์ของคุณ และแสดงผลให้คุณดู ไม่มีสิ่งใดถูกส่งออกไป และคุณคืนสิทธิ์ได้ในคลิกเดียว
  • ตรวจสอบส่วนขยาย ส่วนขยายจะขอสิทธิ์แสดงรายการส่วนขยายที่คุณติดตั้งไว้เฉพาะเมื่อคุณกดปุ่มเท่านั้น และเปรียบเทียบ ID ของส่วนขยายเหล่านั้นกับรายชื่อส่วนขยายที่ทราบว่าเป็นอันตรายภายในเบราว์เซอร์ของคุณ คุณคืนสิทธิ์ได้ในคลิกเดียว

คำขอเครือข่ายที่เกิดขึ้นมีเพียงเท่านี้

ประมาณชั่วโมงละครั้ง ส่วนขยายจะดาวน์โหลดการเปลี่ยนแปลงล่าสุดของฐานข้อมูลภัยคุกคามและกฎการตรวจจับจาก xvoidbyte.github.io ซึ่งโฮสต์โดย GitHub Pages และวันละครั้งจะดาวน์โหลดรายการลิงก์ดาวน์โหลดที่ถูกรายงานทั้งหมด โดยแต่ละไฟล์มีลายเซ็นดิจิทัลกำกับ คำขอเหล่านี้ไม่มีตัวระบุและไม่มีข้อมูลใดๆ เกี่ยวกับการท่องเว็บของคุณ GitHub จะได้รับที่อยู่ IP และเวอร์ชันเบราว์เซอร์ของคุณเช่นเดียวกับเมื่อเปิดหน้าเว็บอื่นๆ ภายใต้ คำชี้แจงความเป็นส่วนตัวทั่วไปของ GitHub คุณปิดการอัปเดตเหล่านี้ได้ในการตั้งค่า แล้วส่วนขยายจะยังคงทำงานต่อด้วยกฎในตัว

หากคุณคลิกลิงก์ "รายละเอียด" ในคำเตือน เบราว์เซอร์ของคุณจะเปิดรายงานสาธารณะบน abuse.ch ในแท็บใหม่ เช่นเดียวกับลิงก์อื่นๆ ที่คุณคลิก

รายงานมาจากที่ใด

ฐานข้อมูลสร้างขึ้นจากโครงการสาธารณะ URLhaus, ThreatFox และ Feodo Tracker ซึ่งดำเนินการโดย abuse.ch ส่วนขยายไม่เคยรายงานสิ่งใดกลับไปยังโครงการเหล่านั้น
