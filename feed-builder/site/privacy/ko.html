ClickFix Warden 개인정보 처리방침

최종 업데이트 2026년 10월 31일

요약

ClickFix Warden은 사용자에 관한 어떤 데이터도 수집하거나, 서버에 저장하거나, 판매하거나, 공유하지 않습니다. 계정, 분석 도구, 원격 분석, 자체 서버가 없습니다. 모든 검사는 브라우저 안에서 이루어집니다.

확장 프로그램이 확인하는 내용과 확인하는 곳

  • 사용자가 여는 페이지의 주소는 브라우저 안에 저장된 공개 위협 데이터베이스 사본과 비교됩니다. 주소는 어디로도 전송되지 않습니다.
  • 페이지가 클립보드에 넣으려는 텍스트와 사용자가 복사하는 텍스트는 숨겨진 명령이 있는지 페이지 안에서 검사됩니다. 어디로도 전송되지 않습니다.
  • 페이지의 텍스트는 "Win 키와 R 키를 누른 다음 Ctrl 키와 V 키를 누르세요" 같은 안내를 찾기 위해 페이지 안에서 읽힙니다. 어디로도 전송되지 않습니다.
  • 웹사이트에 붙여 넣는 텍스트는 인증 코드가 담긴 로그인 링크인지 검사됩니다. 어디로도 전송되지 않습니다.
  • 페이지를 보내는 서버의 IP 주소는 브라우저가 알려 주는 값을 기준으로 로컬 데이터베이스 사본과 비교됩니다.

컴퓨터에 남는 정보

  • 설정과 신뢰하는 사이트 목록.
  • 차단하거나 경고한 내용의 기록. 최대 500개 항목까지 남으며 언제든지 내보내거나 지울 수 있습니다. 로그인 코드는 기록에서 제거됩니다.
  • 다운로드한 위협 데이터베이스와 탐지 규칙의 사본.

설정은 브라우저 동기화가 아닌 브라우저의 로컬 저장소에 보관되므로 브라우저 계정에도 전달되지 않습니다.

선택 검사

  • 방문 기록 검사. 사용자가 버튼을 누를 때만 확장 프로그램이 방문 기록을 읽을 권한을 요청하고, 브라우저 안에서 로컬 데이터베이스와 비교한 뒤 결과를 보여 줍니다. 아무것도 전송되지 않으며, 클릭 한 번으로 권한을 반납할 수 있습니다.
  • 확장 프로그램 검사. 사용자가 버튼을 누를 때만 확장 프로그램이 설치된 확장 프로그램 목록을 볼 권한을 요청하고, 브라우저 안에서 그 ID를 알려진 악성 확장 프로그램 목록과 비교합니다. 클릭 한 번으로 권한을 반납할 수 있습니다.

유일한 네트워크 요청

확장 프로그램은 약 1시간에 한 번 GitHub Pages에서 호스팅되는 xvoidbyte.github.io에서 위협 데이터베이스와 탐지 규칙의 최신 변경 사항을 다운로드하고, 하루에 한 번 신고된 다운로드 링크의 전체 목록을 다운로드합니다. 각 파일에는 디지털 서명이 함께 제공됩니다. 이 요청에는 식별자나 탐색 정보가 전혀 포함되지 않습니다. GitHub는 다른 웹 페이지와 마찬가지로 GitHub 일반 개인정보 보호정책에 따라 사용자의 IP 주소와 브라우저 버전을 받습니다. 설정에서 이 업데이트를 끌 수 있으며, 그러면 확장 프로그램은 기본 제공 규칙으로 계속 작동합니다.

경고에서 "자세히" 링크를 클릭하면 다른 링크를 클릭할 때와 마찬가지로 브라우저가 새 탭에서 abuse.ch의 공개 신고 페이지를 엽니다.

신고 정보의 출처

데이터베이스는 abuse.ch에서 운영하는 공개 프로젝트인 URLhaus, ThreatFox, Feodo Tracker를 바탕으로 만들어집니다. 확장 프로그램은 이 프로젝트들에 아무것도 신고하지 않습니다.

조직

관리자는 브라우저 정책으로 확장 프로그램의 옵션을 설정할 수 있습니다. 이 설정은 브라우저에서 읽히며 역시 어디로도 전송되지 않습니다.
